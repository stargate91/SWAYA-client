# SWAYA Rychlý Start & Přehled

Vítejte v oficiální dokumentaci **SWAYA**! SWAYA je moderní offline mediální centrum pro Windows se zaměřením na soukromí, které vám pomůže organizovat, obohacovat, procházet a přehrávat vaši osobní sbírku médií.

---

## Hlavní Přednosti

SWAYA promění nepřehledné složky stahování v dokonale uspořádanou a vizuálně bohatou knihovnu médií. Ať už spravujete filmy, TV seriály se sezónní strukturou nebo soukromá videa, SWAYA nabízí automatické párování metadat, flexibilní hromadné přejmenování a plynulé 4K MPV přehrávání.

### Klíčové Výhody
1. **Chytrý správce souborů**: Páruje data s předními databázemi (TMDb, StashDB, FansDB) a bezpečně přejmenovává soubory podle standardů Plex/Jellyfin.
2. **Duální režim (SFW / NSFW)**: Plynule přepínejte mezi běžnými médii a obsahem pro dospělé s plným zabezpečením lokálním PIN kódem.
3. **Vysoce výkonný přehrávač**: Integrovaný MPV přehrávač s plnou hardwarovou akcelerací GPU pro 4K HDR.
4. **Bohatá metadata & grafika**: Automaticky stahuje 4K plakáty, pozadí, loga a profily herců.
5. **Osobní správa sbírky**: Vytvářejte vlastní tematické seznamy s kolážemi ze 4 plakátů, 10hvězdičkovým hodnocením a soukromými Markdown poznámkami.
