# Uživatelská Příručka Vlastních Seznamů SWAYA

Funkce **Seznamy (Lists)** umožňuje vytvářet tematické sbírky, sady oblíbených položek a seznamy ke zhlédnutí.

---

## Hlavní Funkce

### 1. Automatické Koláže ze 4 Plakátů
Po vytvoření seznamu a přidání titulů SWAYA automaticky vygeneruje dynamický kolážový obal z prvních 4 plakátů.

### 2. Přetažení Myší (Drag & Drop)
Snadno měňte pořadí filmů a seriálů v seznamu pomocí přetahování myší.

### 3. Export a Import do JSON
Ukládejte své seznamy do souborů JSON pro zálohování nebo přenos mezi počítači.
