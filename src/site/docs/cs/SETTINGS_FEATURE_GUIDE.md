# Uživatelská Příručka Nastavení & Konfigurace SWAYA

V sekci **Nastavení (Settings)** můžete přizpůsobit všechny aspekty přejmenování souborů a chování aplikace.

---

## Hlavní Oblasti Konfigurace

### 1. Šablony Složek a Názvů Souborů
* Konfigurujte vzory pro filmy a seriály (např. `{Title} ({Year})/{Title} - {Resolution}`).
* Definujte formátování štítků verzí (Director's Cut, Extended) a zvukových formátů.

### 2. Služby pro Vyhledávání (Scrapers) & API Klíče
Zadejte své API klíče pro TMDb, OMDb, StashDB, FansDB a ThePornDB.

### 3. Diskrétní Trezor & Klávesové Zkratky
Nastavte globální klávesovou zkratku (Ctrl+Alt+H nebo Esc) pro okamžité skrytí citlivých médií s volitelným PIN kódem.
