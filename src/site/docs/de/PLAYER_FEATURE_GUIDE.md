# SWAYA MPV Player-Leitfaden

Der **integrierte MPV-Player** ist das Wiedergabeherz von SWAYA. Er spielt Filme, Serien und Clips mit Hardwarebeschleunigung, präziser Untertitel-Synchronisation und Kapitelnavigation ab.

---

## Funktionen & Tastenkürzel

SWAYA nutzt eine native **MPV-Engine** für maximale Kompatibilität mit MKV, MP4, 4K HDR, Dolby Atmos und ASS/SRT-Untertiteln.

| Taste | Aktion | Beschreibung |
| :--- | :--- | :--- |
| **Leertaste** | Wiedergabe / Pause | Startet oder pausiert das Video |
| **Enter** | Finish-Moment markieren *(Nur Adult-Modus)* | Speichert einen Screenshot und Zeitstempel |
| **Links / Rechts** | 10s Vor / Zurück | Schnelles Spulen |
| **Oben / Unten** | Lautstärke +/- | Ändert die Lautstärke um 5 % |
| **Doppelklick / F** | Vollbild | Wechselt in den Vollbildmodus |
| **M** | Stummschalten | Schaltet den Ton ein/aus |
| **G / H** | Untertitel-Verzögerung | Passt den Untertitelversatz um 100ms an |
| **J / K** | Audio-Verzögerung | Passt den Tonversatz um 100ms an |
