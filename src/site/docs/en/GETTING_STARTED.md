# Getting Started with SWAYA

Welcome to the **SWAYA** documentation! SWAYA is a modern, privacy-first desktop media workstation designed to organize, enrich, browse, and watch personal media collections.

---

## Quick Overview

SWAYA transforms disorganized video files into a structured, visually engaging media library. Whether you are sorting raw video dumps, organizing multi-season TV shows, or curating custom performer lists, SWAYA provides automated metadata matching, customizable renaming pipelines, and integrated playback with real-time progress tracking.

### Core Pillars
1. **Intelligent File Organizer**: Automated matching against online databases (TMDb, OMDb, StashDB, ThePornDB, FansDB) with custom renaming syntax and conflict resolution.
2. **Dual-Mode Privacy (SFW/NSFW)**: Instant session toggling with server-side image proxying, discrete mode switches, and vault isolation.
3. **High-Performance Playback**: GPU-accelerated embedded MPV player with multi-audio, subtitle rendering, and external player support (VLC, MPC-HC).
4. **Rich Metadata & Artwork**: Automatic high-res poster and backdrop fetching, transparent logos, actor filmographies, studio portfolios, and custom visual art pickers.
5. **Personalized Curation**: Custom lists with collage artwork, granular 10-star rating system with half-star steps, tag focus modes, and in-depth watch logs.
