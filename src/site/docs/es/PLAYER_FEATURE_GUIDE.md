# Guía del Reproductor MPV Integrado SWAYA

El **Reproductor MPV Integrado** es el motor de video de SWAYA. Ofrece reproducción fluida en 4K HDR con aceleración por hardware, sincronización de subtítulos y navegación por capítulos.

---

## Atajos de Teclado y Controles

| Tecla | Acción | Descripción |
| :--- | :--- | :--- |
| **Espacio** | Reproducir / Pausa | Alterna entre reproducir y pausar |
| **Enter** | Registrar momento clave *(Solo modo adultos)* | Captura de pantalla y marca de tiempo |
| **Izquierda / Derecha** | Retroceder / Avanzar 10s | Búsqueda rápida |
| **Arriba / Abajo** | Volumen +/- | Ajusta el volumen en pasos del 5% |
| **Doble clic / F** | Pantalla completa | Alterna el modo de pantalla completa |
| **M** | Silenciar | Activa o desactiva el silencio |
| **G / H** | Retardo de subtítulos | Ajusta el desfase de subtítulos (±100ms) |
| **J / K** | Retardo de audio | Ajusta el desfase de audio (±100ms) |
