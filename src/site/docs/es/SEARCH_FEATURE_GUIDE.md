# Guía de Búsqueda y Descubrimiento SWAYA

La búsqueda universal de SWAYA te permite encontrar películas, series, actores y escenas de manera instantánea.

---

## 1. Métodos de Búsqueda

* **Búsqueda Rápida en la Barra Superior:** Sugerencias automáticas mientras escribes. Presiona **Enter** para ver la página completa.
* **Página de Búsqueda Completa:** Visualización en pósteres grandes con filtros por origen (TMDb, StashDB, FansDB, ThePornDB).

## 2. Modo Seguro y Privacidad

* **Contenido para Adultos DESACTIVADO:** Solo busca títulos aptos para todo público.

* **Contenido para Adultos ACTIVADO en modo NSFW:** Todas las imágenes se visualizan con máxima nitidez.
