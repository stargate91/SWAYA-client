# Guide du Lecteur MPV Intégré SWAYA

Le **Lecteur MPV Intégré** est le moteur de lecture vidéo de SWAYA. Il assure une lecture 4K HDR fluide avec accélération matérielle, synchronisation des sous-titres et gestion des chapitres.

---

## Raccourcis Clavier & Contrôles

| Touche | Action | Description |
| :--- | :--- | :--- |
| **Espace** | Lecture / Pause | Bascule entre lecture et pause |
| **Entrée** | Enregistrer un moment clé *(Mode adulte)* | Capture d'écran et horodatage |
| **Gauche / Droite** | Reculer / Avancer 10s | Navigation rapide |
| **Haut / Bas** | Volume +/- | Ajuste le volume par paliers de 5 % |
| **Double-clic / F** | Plein écran | Bascule le mode plein écran |
| **M** | Muet | Coupe ou réactive le son |
| **G / H** | Décalage des sous-titres | Ajuste la synchronisation des sous-titres (±100ms) |
| **J / K** | Décalage audio | Ajuste la synchronisation audio (±100ms) |
