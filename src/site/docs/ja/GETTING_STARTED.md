# SWAYAをはじめよう

**SWAYA**の公式ドキュメントへようこそ！SWAYAは、個人のメディアコレクションを整理・充実・閲覧・再生するための、プライバシー重視の最新デスクトップメディアワークステーションです。

---

## クイック概要

SWAYAは、乱雑な動画ファイルを美しく構造化されたライブラリへと変貌させます。ダウンロード動画の仕分け、TVアニメやドラマの整理、お気に入り出演者リストの作成など、自動メタデータ照合、カスタムリネーム、シームレスな再生環境を提供します。

### 主な柱
1. **スマートファイル整理**: オンラインデータベース（TMDb、StashDB、FansDBなど）と自動照合し、重複を防ぎながらリネーム・フォルダ分類。
2. **デュアルモード（SFW/NSFW）**: ワンクリックで一般・成人向けモードを瞬時に切り替え、プライバシーを保護。
3. **高性能再生エンジン**: GPUハードウェアアクセラレーション対応の内蔵MPVプレイヤー。
4. **リッチなメタデータ & アートワーク**: 4Kポスター、背景画像、透明ロゴ、出演者プロフィールを自動取得。
5. **柔軟なカスタム管理**: コラージュ付きリスト、10段階評価、詳細な視聴ログ。
