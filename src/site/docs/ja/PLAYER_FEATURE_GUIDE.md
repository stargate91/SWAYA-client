# SWAYA MPVプレイヤーガイド

**内蔵MPVプレイヤー**は、SWAYAの再生エンジンです。ハードウェアアクセラレーション、高精度字幕同期、チャプターナビゲーションを備えています。

---

## 主な機能 & ショートカットキー

ネイティブな**MPVエンジン**を搭載し、MKV、MP4、4K HDR、Dolby Atmos、ASS/SRT字幕などあらゆる形式を軽快に再生します。

| キー | 操作 | 説明 |
| :--- | :--- | :--- |
| **スペース** | 再生 / 一時停止 | 再生状態の切り替え |
| **Enter** | フィニッシュ記録 *(成人モードのみ)* | 決定的瞬間のスクリーンショットと時間を記録 |
| **左 / 右** | 10秒 戻る / 進む | 早送り・巻き戻し |
| **上 / 下** | 音量 +/- | 音量を5%ずつ調整 |
| **ダブルクリック / F** | 全画面表示 | 全画面表示の切り替え |
| **M** | ミュート | 消音の切り替え |
| **G / H** | 字幕タイミング調整 | 字幕の表示タイミングを100ms早める/遅らせる |
| **J / K** | 音声タイミング調整 | 音声のズレを100ms早める/遅らせる |
