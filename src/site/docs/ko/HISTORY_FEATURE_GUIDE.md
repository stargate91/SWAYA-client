# SWAYA 시청 기록 & 로그 가이드

**시청 기록(History)** 기능은 사용자의 미디어 감상 내역과 파일 변경 이력을 안전하게 기록합니다.

---

## 주요 기능

### 1. 재생 진행률 자동 저장
영상을 시청하다가 중단하면 마지막 재생 시점을 자동으로 저장하여 언제든 즉시 이어서 감상할 수 있습니다.

### 2. 시청 완료(Watched) 상태 관리
시청 완료율이 90% 이상 도달하면 자동으로 '시청 완료' 배지가 부여되며, 원클릭으로 시청 상태를 수동 전환할 수 있습니다.

### 3. 파일 정리 이력 & 롤백 확인
오거나이저에서 실행한 일괄 파일 이름 변경 내역을 확인하고 이전 파일명 정보를 검토할 수 있습니다.
