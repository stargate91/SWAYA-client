# SWAYA 라이브러리 & 카탈로그 가이드

**라이브러리(Library)**는 사용자의 모든 미디어 자산을 탐색, 검색, 필터링할 수 있는 메인 카탈로그입니다.

---

## 핵심 기능

### 1. 반응형 포스터 그리드
GPU 가속 가상 스크롤 렌더링으로 수만 편의 영화와 에피소드가 있어도 버벅임 없이 즉시 스크롤됩니다.

### 2. 다차원 정렬 & 필터링
* 출시 연도, 추가된 날짜, 평점, 해상도(4K, 1080p), 비디오 코덱(HEVC, AV1) 등 다양한 조건으로 즉시 필터링.
* 사용자 정의 태그를 조합하여 원하는 미디어만 빠르게 추출.

### 3. 외장 드라이브 분리 지원
하드 드라이브가 오프라인 상태여도 메타데이터, 포스터, 출연진 정보는 로컬 SQLite 데이터베이스에 보존되어 언제든 열람할 수 있습니다.
