# SWAYA 커스텀 리스트 & 컬렉션 가이드

**리스트(Lists)** 기능을 통해 테마별 컬렉션, 마라톤 시청 목록, 추천 영화 리스트를 손쉽게 큐레이션할 수 있습니다.

---

## 주요 기능

### 1. 자동 4-포스터 콜라주 커버
리스트를 생성하고 미디어를 추가하면, 리스트 첫 4개 작품의 포스터를 자동으로 조합하여 고품질 콜라주 커버를 실시간 생성합니다.

### 2. 드래그 앤 드롭 정렬
사용자 정의 순서로 영화나 에피소드의 순서를 자유롭게 드래그하여 시청 순서를 지정할 수 있습니다.

### 3. JSON 가져오기 / 내보내기
생성한 커스텀 리스트를 JSON 파일로 백업하거나 다른 기기의 SWAYA와 손쉽게 공유할 수 있습니다.
