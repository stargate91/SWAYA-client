# SWAYA 파일 정리 & 오거나이저 가이드

**오거나이저(Organizer)**는 SWAYA의 핵심 분류 워크스테이션입니다. 다운로드 폴더의 복잡한 영상 파일명을 자동으로 분석하고, 제목과 출연진 정보를 검색하여 정돈된 폴더 구조로 정리합니다.

---

## 2가지 정리 방식

### 1. 정리, 이름 변경 & 이동 (기본값)
지저분한 파일명을 표준 규격으로 변환하고(예: `Inception.2010.1080p.mkv` $\rightarrow$ `Inception (2010) [1080p].mkv`), 지정된 라이브러리 폴더로 자동 이동합니다.

### 2. 제자리에서 인제스트 (파일 이동 없음)
토렌트 시딩 중이거나 기존 드라이브 구조를 그대로 유지하고 싶다면 **In-Place(제자리 정리)**를 선택합니다.
* 메타데이터와 포스터 아트워크만 라이브러리로 가져오며, 하드 드라이브의 실제 파일명과 경로는 그대로 유지됩니다.
* **사용 방법:** 상단 우측 'Rename' 버튼 오른쪽의 화살표를 누르고 'Organize In-Place'를 선택합니다.
