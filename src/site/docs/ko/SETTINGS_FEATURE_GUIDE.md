# SWAYA 환경설정 & 구성 가이드

**환경설정(Settings)** 페이지에서 SWAYA의 모든 동작 방식과 명명 규칙을 맞춤 설정할 수 있습니다.

---

## 주요 설정 영역

### 1. 폴더 명명 템플릿
* 영화 및 TV 시리즈 폴더 구조 정의 (예: `{Title} ({Year})/{Title} - {Resolution}`).
* 에디션 태그(Director's Cut, Extended) 및 오디오 포맷 표기 규칙 설정.

### 2. 스크레이퍼 및 API 키
TMDb, OMDb, StashDB, FansDB, ThePornDB API 키를 등록하여 자동 메타데이터 수집을 활성화합니다.

### 3. 스텔스 금고 및 단축키
민감한 라이브러리를 가리기 위한 스텔스 금고 핫키(Ctrl+Alt+H 또는 Esc) 및 복구 비밀번호를 구성합니다.
