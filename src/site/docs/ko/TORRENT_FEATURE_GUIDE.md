# SWAYA 토렌트 클라이언트 연동 가이드

SWAYA는 외부 토렌트 클라이언트(qBittorrent, Transmission 등)와 직접 연동되는 대시보드를 제공합니다.

---

## 주요 기능

### 1. 실시간 다운로드 모니터링
앱을 벗어나지 않고도 활성 다운로드 속도, 업로드 속도, 시더 수, 잔여 시간을 실시간 확인합니다.

### 2. 다운로드 완료 시 자동 인제스트
토렌트 다운로드가 100% 완료되면 백그라운드 워처가 이를 감지하여 SWAYA 오거나이저로 자동 전달하고 정리합니다.

### 3. 인앱 토렌트 검색
연동된 트래커를 통해 원하는 콘텐츠의 마그넷 링크를 검색하고 원클릭으로 클라이언트에 전달할 수 있습니다.
