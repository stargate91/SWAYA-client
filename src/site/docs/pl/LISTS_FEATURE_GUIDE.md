# Podręcznik List Niestandardowych SWAYA

Funkcja **Listy (Lists)** pozwala tworzyć kolekcje tematyczne, zestawy ulubionych i listy do obejrzenia.

---

## Główne Funkcje

### 1. Automatyczne Okładki Kolażowe z 4 Plakatów
Po utworzeniu listy i dodaniu pozycji, SWAYA automatycznie generuje dynamiczną okładkę w formie kolażu z pierwszych 4 plakatów.

### 2. Przeciągnij i Upuść (Drag & Drop)
Łatwo zmieniaj kolejność filmów i seriali na liście za pomocą przeciągania elementów.

### 3. Eksport & Import JSON
Zapisuj listy do plików JSON w celu tworzenia kopii zapasowych lub przenoszenia między komputerami.
