# Podręcznik Ustawień & Konfiguracji SWAYA

W sekcji **Ustawienia (Settings)** możesz dostosować wszystkie aspekty zmiany nazw plików i działania aplikacji.

---

## Główne Obszary Konfiguracji

### 1. Szablony Nazw Folderów i Plików
* Konfiguruj wzorce dla filmów i seriali (np. `{Title} ({Year})/{Title} - {Resolution}`).
* Określaj formatowanie tagów edycji (Director's Cut, Extended) i formatów audio.

### 2. Skrobaki (Scrapers) & Klucze API
Wprowadź swoje klucze API dla TMDb, OMDb, StashDB, FansDB i ThePornDB.

### 3. Dyskretny Sejf & Skróty Klawiszowe
Skonfiguruj globalny skrót klawiszowy (Ctrl+Alt+H lub Esc) do natychmiastowego ukrywania wrażliwych bibliotek z opcjonalną blokadą PIN.
