# Руководство по Поиску и Исследованию в SWAYA

Поиск фильмов, сериалов, актеров и сцен в SWAYA работает невероятно быстро и удобно. Это руководство рассказывает о возможностях поискового движка, уровнях приватности и доступных источниках данных.

---

## Как устроен поиск

В SWAYA доступны два удобных способа поиска:

```
                      [ Введите поисковый запрос ]
                                     │
                 ┌───────────────────┴───────────────────┐
                 ▼                                       ▼
     ┌───────────────────────┐               ┌───────────────────────┐
     │   Быстрый поиск       │               │   Полноэкранный поиск │
     │   (Верхняя панель)    │               │   (Сетка и фильтры)   │
     ├───────────────────────┤               ├───────────────────────┤
     │ • Мгновенные подсказки│               │ • Крупные постеры     │
     │ • Клавиатурное управл.│               │ • Вкладки источников  │
     │ • Быстрый переход     │               │ • Фильтры категорий   │
     └───────────────────────┘               └───────────────────────┘
```

1. **Быстрый поиск в верхней панели:**
   * Кликните на строку поиска вверху и начните вводить текст.
   * Мгновенные подсказки появляются под строкой в компактном списке.
   * **3 способа открыть полную страницу поиска:**
     * **Иконка со стрелкой справа:** Прямой переход к странице поиска.
     * **Нажатие Enter:** Моментальный переход с введенным запросом.
     * **Кнопка «Показать все результаты...» внизу списка.**
   * Используйте **Стрелки вверх/вниз** для навигации и **Escape** для закрытия.

2. **Полноэкранный поиск:**
   * Удобен для просмотра сотен результатов на просторной сетке с постерами.
   * Переключение между базами данных (TMDb, StashDB и др.) в один клик.
   * Фильтрация по Фильмам, Сериалам, Актерам или Студиям.
   * Кнопка **Загрузить еще (+20)** внизу страницы для бесконечного исследования.

## Безопасный режим и приватность (Safe Mode)

SWAYA гарантирует, что деликатный контент никогда не появится на экране случайно.

### 3 уровня безопасности:

1. **Контент для взрослых отключен в Настройках (Семейный режим):**
   * SWAYA ищет исключительно мейнстрим-фильмы и сериалы. Контент 18+ полностью исключен из поиска.
2. **Контент для взрослых включен, но активен режим SFW (Значок пламени выключен):**
   * Вы можете искать сцены и моделей, но **все обложки и превью автоматически заблюрены защитным экраном**.
3. **Контент для взрослых включен и активен режим NSFW (Значок пламени включен):**
   * Все постеры, фоны и фотографии актеров отображаются в полном качестве.

## Источники и типы поиска

Выбирайте базу данных с помощью кнопок **Источник** и **Тип** вверху страницы:

| Источник | Доступные типы |
| :--- | :--- |
| **TMDb** *(Мейнстрим)* | Всё, Фильмы, Сериалы, Звезды (Актеры), Коллекции, Студии |
| **StashDB** | Сцены, Звезды для взрослых, Студии |
| **FansDB** | Сцены, Звезды для взрослых, Студии |
| **ThePornDB** | Сцены, Фильмы для взрослых, Звезды, Студии |

### Значение категорий:
* **Всё:** Одновременный поиск по фильмам, сериалам, персонам и франшизам.
* **Фильмы:** Полнометражные ленты с постерами, датами и хронометражем.
* **Сериалы:** ТВ-шоу с количеством сезонов и датами трансляций.
* **Звезды / Актеры:** Профили актеров с фото, биографиями и ролями.
* **Коллекции:** Объединенные киноциклы (например, *Гарри Поттер*, *Звездные войны*).
* **Студии:** Производственные студии и сети (например, *Warner Bros*, *Disney*, *HBO*).
* **Сцены:** Видеоклипы и сцены со списками актеров, студиями и датами.
