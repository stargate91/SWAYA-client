# Руководство по Настройкам и Конфигурации в SWAYA

Раздел **Настроек (Settings)** - это командный центр SWAYA. Он позволяет настроить правила сканирования, распознавания, переименования и структуры папок на диске, выбрать видеоплеер, кастомизировать интерфейс с помощью более чем 30 тем и управлять скраперами метаданных.

---

## Общая архитектура

Все компоненты SWAYA используют настройки в реальном времени:

```
 ┌──────────────────────┐      ┌────────────────────────┐      ┌──────────────────────┐
 │    ВХОДЯЩИЕ МЕДИА    │ ───► │      ДВИЖОК SWAYA      │ ───► │УПОРЯДОЧЕННАЯ БИБЛИОТ.│
 │ Хаотичные загрузки и │      │ Сопоставляет данные,   │      │ Аккуратные папки,    │
 │ исходные файлы видео │      │ форматирует имена      │      │ постеры и субтитры   │
 └──────────────────────┘      └───────────┬────────────┘      └──────────────────────┘
                                           │
                        Считывает правила из раздела
                                  НАСТРОЙКИ
```

## Раздел 1: 3 режима организации медиа

SWAYA поддерживает три метода управления файлами на накопителях:

| Режим | Действие на диске |
| :--- | :--- |
| **1. Перемещение и организация** | Перемещает файлы из папки загрузок в структурированные подпапки (например, `Фильмы/Inception (2010)/Inception (2010) [1080p].mkv`). |
| **2. Переименование на месте** | Переименовывает файлы по шаблону в их текущей директории без перемещения. |
| **3. Только регистрация** | Добавляет файлы в базу данных SWAYA и загружает обложки без изменения имен и путей на диске. |

## Раздел 2: Движок именования и структуры

### 1. Готовые пресеты и ручная настройка

В разделе **Организация > Пресеты** можно выбрать общепринятые форматы:

* **Plex:** `Фильмы/Inception (2010)/Inception (2010) [1080p].mkv` и `Сериалы/Breaking Bad/Season 01/Breaking Bad - S01E01.mkv`
* **Jellyfin / Emby:** `Фильмы/Inception (2010)/Inception (2010).mkv` с артами `backdrop.jpg` и `logo.png`
* **Kodi:** Структура с метками года и разрешения.
* **Минимальный:** Лаконичные имена без вложенных папок.

### 2. Разрешение коллизий (`Стратегия дубликатов`)
* `Заменять лучшим` *(Рекомендуется)*: Сравнивает разрешение (4K > 1080p > 720p), битрейт и каналы звука, сверяя длительность для защиты от замены фильма сэмплом.
* `Сохранять оба`: Добавляет к новому файлу порядковый номер (например, `Inception (2010) [1].mkv`).
* `Перезаписывать`: Безусловная перезапись существующего файла.
* `Пропускать`: Оставляет исходный файл без изменений.

### 3. Динамические теги шаблонов
* `{title}`: Официальное название
* `{year}`: 4-значный год выпуска
* `{resolution}`: Качество видео (`1080p`, `2160p (4K)`)
* `{edition}`: Версия издания (`Director's Cut`, `Extended`)
* `{show}`, `{season}`, `{episode}`: Сериал, сезон и серия (`S01E01`)
* `{studio}`, `{performers}`, `{date}`: Студия, актеры и дата премьеры

## Раздел 3: Основные параметры приложения

1. **Общие:** Профиль пользователя, папка входящих загрузок, целевая папка медиатеки и язык интерфейса.
2. **Внешний вид и темы:** Более 30 цветовых схем (Классическая темная, Tokyo Night, Dracula, AMOLED Modern, Synthwave, Cyberpunk, Nord).
3. **Плеер и языки:** Выбор между встроенным плеером, VLC или MPC-HC; умный выбор звуковых дорожек и автоматические субтитры.
4. **Контент для взрослых и фильтры:** Отдельная изолированная папка, фильтрация по полу актеров и черный список тегов для рекомендаций.
5. **Интеграция API:** Подключение ключей TMDb, OMDb, StashDB, FansDB и ThePornDB.
6. **Торренты:** Интеграция с qBittorrent и Jackett для поиска и загрузок прямо в SWAYA.
7. **Обслуживание и резервное копирование:** Экспорт/импорт настроек в `.json`, очистка кэша обложек и сброс параметров.

## Горячие клавиши
* **`Ctrl + S` / `Cmd + S`:** Мгновенное сохранение изменений.
* **Поиск в боковой панели:** Быстрая фильтрация вкладок по ключевым словам (например, *"tmdb"*, *"vlc"*, *"субтитры"*).
