# Kom igång med SWAYA

Välkommen till den officiella dokumentationen för **SWAYA**! SWAYA är ett integritetsfokuserat, modernt och offlinebaserat mediacenter för Windows som hjälper dig att organisera, berika, bläddra i och spela upp din lokala mediesamling.

---

## Kärnfunktioner i översikt

SWAYA förvandlar ostrukturerade nedladdningsmappar till ett perfekt organiserat och visuellt tilltalande mediebibliotek. Oavsett om du hanterar filmer, TV-serier med säsongsstruktur eller privata videoklipp, erbjuder SWAYA automatisk metadatamatchning, flexibel massnamnändring och sömlös 4K MPV-uppspelning.

### Huvudfördelar
1. **Smart filorganisatör**: Matchar mot ledande databaser (TMDb, StashDB, FansDB) och byter namn på filer säkert enligt Plex/Jellyfin-standard.
2. **Dubbelläge (SFW / NSFW)**: Växla smidigt mellan allmänna medier och vuxeninnehåll med fullständig lokal PIN-kodssäkerhet.
3. **Högpresterande spelarmotor**: Inbyggd MPV-videospelare med full hårdvaruacceleration (GPU) för 4K HDR.
4. **Rik metadata & konstverk**: Hämtar automatiskt 4K-affischer, bakgrundsbilder, logotyper och skådespelarprofiler.
5. **Personlig kuratering**: Skapa anpassade temalistor med 4-affischers collageomslag, 10-stjärnigt betygssystem och privata Markdown-anteckningar.
