# Användarhandbok för SWAYA Anpassade Listor

Med **Listor (Lists)** kan du skapa temasamlingar, favoritlistor och att-se-listor.

---

## Huvudfunktioner

### 1. Automatiska 4-Affischers Collageomslag
När du skapar en lista och lägger till titlar genererar SWAYA automatiskt ett dynamiskt collageomslag baserat på de första 4 affischerna.

### 2. Dra och Släpp (Drag & Drop)
Ändra enkelt ordningen på filmer och serier i listan med hjälp av dra-och-släpp.

### 3. JSON-export & Import
Spara dina listor till JSON-filer för säkerhetskopiering eller flytt mellan olika datorer.
