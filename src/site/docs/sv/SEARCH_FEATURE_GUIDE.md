# Användarhandbok för SWAYA Universell Sökning

**Universell Sökning (Search)** låter dig söka samtidigt i ditt lokala bibliotek och i externa onlinedatabaser.

---

## Sökfunktioner

### 1. Globalt Snabbkommando (Ctrl+K)
Tryck på `Ctrl+K` var som helst i programmet för att omedelbart öppna sökpanelen.

### 2. Samtidig Sökning över Flera Entiteter
Sök samtidigt efter filmtitlar, serier, enskilda avsnitt, skådespelare, regissörer och taggar.

### 3. Direkt Onlinesökning
Sök i TMDb efter filmer du ännu inte äger för att se deras beskrivningar och trailers.
