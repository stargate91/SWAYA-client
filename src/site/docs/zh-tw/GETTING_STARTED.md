# SWAYA 快速入門與概覽

歡迎閱讀 **SWAYA** 官方說明文件！SWAYA 是一款專為 Windows 設計、注重隱私的現代化離線桌面影音工作站，旨在幫助你整理、豐富、瀏覽並播放個人影音收藏。

---

## 核心功能亮點

SWAYA 能將混亂的下載資料夾瞬間轉換為條理分明的精美影音庫。無論是整理電影、影集季數結構，還是管理個人私密影片，SWAYA 都能提供自動化元資料比對、靈活的批次命名與無縫的 4K MPV 原畫質播放。

### 主要優勢
1. **智慧檔案整理器**：自動比對線上權威資料庫（TMDb、StashDB、FansDB），安全重新命名並依照標準規範歸檔。
2. **雙重模式（SFW / NSFW）**：一鍵在一般影音與成人內容之間無縫切換，具備完整的本機密碼保護。
3. **高效能播放核心**：內建經過最佳化的 MPV 播放器，支援完整的 GPU 硬體解碼。
4. **豐富元資料與視覺海報**：自動抓取 4K 海報、背景劇照、透明 Logo 與演職員個人檔案。
5. **個人專屬收藏**：自訂主題清單、動態 4 海報拼貼封面、10 分制評分與私密 Markdown 筆記。
