# SWAYA 檔案整理器使用手冊

**整理器 (Organizer)** 是 SWAYA 的核心工作站。它能自動識別下載資料夾中的混亂檔名，抓取對應元資料，並依照規範整理至結構化的目錄中。

---

## 兩種整理方式

### 1. 整理、重新命名並移動（預設推薦）
將混亂的檔名（如 `Inception.2010.1080p.mkv` $\rightarrow$ `Inception (2010) [1080p].mkv`）轉換為標準格式，並自動歸檔至對應的媒體庫資料夾。

### 2. 就地整理 / In-Place（保持實體檔案不變）
想要持續做種 (Seeding) 或維持現有的硬碟目錄結構？請選擇 **In-Place（就地整理）**。
* 僅抓取元資料與海報圖片，實體檔案路徑與檔名完全不變。
* **操作方式：** 點擊右上角「Rename」按鈕旁邊的下拉箭頭，選擇「Organize In-Place」。

---

## 雙重模式與資料來源

* **一般模式 (SFW)：** 透過 **TMDb** 自動識別電影、電視影集與動畫。
* **成人模式 (NSFW)：** 透過 **StashDB**、**FansDB** 與 **ThePornDB** 進行精確比對。
* **離線模式：** 無需任何 API 金鑰即可直接匯入個人私有錄影與自製影片。
