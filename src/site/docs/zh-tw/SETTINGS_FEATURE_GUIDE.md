# SWAYA 偏好設定與架構配置指南

在 **設定 (Settings)** 頁面中，你可以依據個人習慣調整檔案重新命名規範與介面外觀。

---

## 主要設定模組

### 1. 資料夾與檔名範本
* 自訂電影與影集的資料夾階層結構（例如 `{Title} ({Year})/{Title} - {Resolution}`）。
* 設定特殊版本標籤（導演剪輯版、加長版）與音訊編碼之格式化字串。

### 2. 資料庫抓取器 (Scrapers) & API 金鑰
設定 TMDb、OMDb、StashDB、FansDB 與 ThePornDB 之 API 金鑰以啟用自動比對。

### 3. 隱形保險庫與緊急快捷鍵
自訂全域防窺快捷鍵（Ctrl+Alt+H 或 Esc）及 PIN 碼，在必要時瞬間隱藏敏感媒體庫。
