## 快速概览

SWAYA 能将杂乱无章的视频下载目录，秒级转变为美观整洁、信息丰富的影视媒体库。无论是归档最新下载、整理多季连续剧，还是制作演员影人专题，SWAYA 都能提供全自动元数据刮削匹配、自定义批量重命名与硬件加速播放。

### 核心支柱
1. **智能文件整理器**：对接主流及专业数据库（TMDb、OMDb、StashDB、ThePornDB、FansDB），支持自定义命名模板与冲突替换防护。
2. **双模式隐私切换 (SFW/NSFW)**：顶部导航秒级无感切换，内置图片防窥代理与隐身金库模式。
3. **极速播放引擎**：内置 MPV 原生内核，支持 GPU 硬件加速解码、多音轨与字幕精准切换。
4. **4K 高清海报与元数据**：自动抓取高清海报、剧照背景画、透明 Logo、演职员作品年表与厂牌资料。
5. **个性化精细管理**：主题片单支持4图自动拼图封面、10星细化评分与私密 Markdown 影评。
