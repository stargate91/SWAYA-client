# SWAYA 文件整理与管理指南

**整理器（Organizer）**是 SWAYA 的智能分拣中心。它能扫描你混乱的下载文件夹，自动识别对应的电影、电视剧或视频片段，下载高清海报与元数据，并将硬盘中的物理文件规范整理。

---

## 工作机制：2 种整理模式

### 1. 整理、重命名并移动归档（默认模式）
SWAYA 会清理混乱的文件名（例如将 `Inception.2010.1080p.mkv` 重构为 `The Matrix (1999) [1080p].mkv`），在你的目标硬盘上建立规范的层级目录，并将物理文件移入正式媒体库。

### 2. 原地导入（保持物理文件与目录完全不变）
如果你正在做种保种，或者不想改动现有的硬盘文件结构，可以选择**原地整理（In-Place）**：
* SWAYA 仅抓取所有元数据、海报、演职员及评分存入媒体库。
* 硬盘上的物理文件保留在原路径，文件名保持不变。
* **使用方式：** 点击右上角“重命名”按钮右侧的小箭头，选择“原地整理”。

---

## 双模式支持与数据源

* **常规模式 (SFW)：** 通过 **TMDb** 自动识别电影与剧集。
* **成人模式 (NSFW)：** 通过 **StashDB**、**FansDB** 和 **ThePornDB** 高精度识别视频片段与影视作品。
* **离线视频模式：** 无需任何 API 密钥即可直接入库，专为家庭录像与自制视频设计。
