# SWAYA MPV 播放器使用指南

**内置 MPV 播放器**是 SWAYA 的媒体播放核心。支持 4K HDR 硬件加速解码、字幕精细同步调节与章节标记。

---

## 常用快捷键与操作说明

内置原生 **MPV 引擎**，完美支持 MKV、MP4、4K HDR、Dolby Atmos 以及 ASS/SRT 字幕。

| 按键 | 功能 | 说明 |
| :--- | :--- | :--- |
| **空格键 (Space)** | 播放 / 暂停 | 切换播放与暂停状态 |
| **回车键 (Enter)** | 记录高光瞬间 *(仅限成人模式)* | 截取高清帧并保存时间戳 |
| **左 / 右方向键** | 快退 / 快进 10秒 | 快速跳转进度 |
| **上 / 下方向键** | 音量 +/- | 以 5% 步长增减音量 |
| **双击 / F键** | 全屏切换 | 进入或退出全屏模式 |
| **M键** | 静音切换 | 开启或关闭静音 |
| **G / H键** | 字幕延迟微调 | 提前或推迟字幕显示时间 (±100ms) |
| **J / K键** | 音频延迟微调 | 修正音画不同步问题 (±100ms) |
