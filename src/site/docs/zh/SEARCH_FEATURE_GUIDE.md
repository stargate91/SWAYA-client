# SWAYA 搜索与探索指南

SWAYA 的全局搜索功能可帮助你快速找到任何电影、连续剧、演员与视频片段。

---

## 1. 搜索方式

* **顶部快捷搜索栏：** 输入即时弹出建议，按 **Enter** 键可直达完整大图搜索页。
* **完整搜索页面：** 大海报网格视图，支持按 TMDb、StashDB、FansDB 和 ThePornDB 分源过滤。

---

## 2. 安全模式与隐私保护

* **成人内容关闭：** 仅搜索全年龄向主流影视资源。
* **成人内容开启但处于常规 (SFW) 模式：** 所有敏感海报**自动高斯模糊处理 (Blur)**。
* **成人内容开启且处于成人 (NSFW) 模式：** 所有封面高清原图完整显示。
