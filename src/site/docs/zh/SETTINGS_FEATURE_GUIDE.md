# SWAYA 设置与配置指南

**设置（Settings）**页面是你的中央控制面板，用于自定义文件扫描、命名规则、视觉主题与第三方 API。

---

## 1. 命名模板与预设

一键选择行业通用标准布局（**Plex**、**Jellyfin/Emby**、**Kodi**、**Minimal**），或使用 `{title}`、`{year}`、`{resolution}`、`{edition}` 等动态标签构建完全自定义的命名规则。

---

## 2. 冲突解决策略与视觉主题

* **Replace if better（更佳画质自动替换）：** 仅当新入库文件的分辨率更高（4K > 1080p）或码率更高时才自动替换旧文件。
* **视觉主题：** 提供超过 30 款精心调配的深色主题（*Tokyo Night*、*Dracula*、*Matrix Code*、*AMOLED Modern* 等），支持实时预览应用。
