# SWAYA Torrent 与下载联动指南

在 SWAYA 中查找并下载影视资源非常简单，且全流程无缝内嵌。

---

## 1. 3 步快速配置

1. **启用下载联动：** 进入 **设置 > Torrent 联动**，开启自动化开关。
2. **连接 qBittorrent：** 在 qBittorrent 中开启 Web UI（默认端口 `8080`），并将连接信息填入 SWAYA。
3. **在 Jackett 中添加索引器：** 点击打开 Jackett 控制台，添加你常用的公开或私有 Tracker 站点。

---

## 2. 检索与下载任务管理

* **一键检索：** 在任何电影或剧集的详情页中点击下载图标，SWAYA 将自动填入标题与年份进行搜索。
* **下载管理：** 在左侧边栏的“下载”页面中实时查看下载速度、暂停、继续或管理保种 (Seeding)。
